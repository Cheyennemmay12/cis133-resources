# CIS 133 Resources

These resources are especially useful for a CIS 133 course because they reinforce foundational computer concepts, web technologies, and practical problem-solving in a clear, beginner-friendly way. I chose tools that explain topics in plain language, provide hands-on practice, and help build confidence before moving into more advanced material.

## Recommended Resources

### 1. MDN Web Docs
https://developer.mozilla.org/

MDN is one of the best places to learn HTML, CSS, JavaScript, and web development basics. It is especially helpful because it explains concepts in a clear, reliable way and includes real-world examples that students can use while practicing.

### 2. W3Schools
https://www.w3schools.com/

W3Schools is a practical resource for learning the basics of HTML, CSS, JavaScript, and other web technologies. It is useful for quick reference, small examples, and step-by-step practice because it makes difficult topics feel approachable.

### 3. freeCodeCamp
https://www.freecodecamp.org/

freeCodeCamp offers structured lessons and hands-on projects that help students apply what they learn. I like it because it emphasizes real practice, which helps learners retain information better than reading alone.

### 4. GitHub Docs
https://docs.github.com/

GitHub is essential for version control and collaboration, and GitHub Docs explains how to use the platform effectively. This resource is valuable because it covers the tools students often need for assignments, teamwork, and professional coding workflows.

### 5. Codecademy
https://www.codecademy.com/

Codecademy is a good beginner resource because it turns learning into interactive exercises. It is especially effective for building confidence with coding fundamentals through immediate feedback and guided practice.

### 6. Linux Journey
https://linuxjourney.com/

Linux Journey is a helpful resource for learning command-line skills, file systems, and basic system concepts. It is valuable because many IT and computing courses rely on Linux or terminal-based workflows, and this site explains them in an accessible format.

### 7. CS50 (Harvard OpenCourseWare)
https://cs50.harvard.edu/x/

CS50 introduces core computer science ideas in a way that is both engaging and intellectually rigorous. I recommend it because it helps students understand the bigger picture behind programming and technology, not just isolated commands or syntax.

## Final Thoughts

These resources work well together because they balance explanation, practice, and real-world application. If a student uses a mix of reference guides, interactive tutorials, and structured courses, they will likely build both the technical skills and confidence needed for success in CIS 133.
